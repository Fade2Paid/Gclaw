# Session Kickoff — paste this first, every time

> When you open a new terminal (Claude Code) session on a project, your FIRST
> message should reload the desk and gate Claude before it acts. Don't rely on
> memory — copy from here.

---

## Your YouTube pipeline project (`~/youtube-content-pipeline`)

Paste this as the first message:

```
Read the global CLAUDE.md, my skills, and PRD.md. Before doing anything,
tell me your understanding of:
1. what this project is,
2. the rules you must follow (global, money, video),
3. where we left off and what's next.
Then wait for me to confirm before you act.
```

---

## Any other project (the universal version)

```
Read CLAUDE.md (and PLAN.md / the plan doc if one exists). Before doing
anything, tell me your understanding of:
1. what this project is,
2. the rules you must follow,
3. what we're doing right now.
Then wait for me to confirm before you act.
```

---

## Why this is the right first move

It does three things you learned:

1. **Loads the desk** — pulls your pinned rules back into context so Claude
   isn't starting blank.
2. **Proves it read them** — Claude has to report the project + rules back, so
   you catch a misunderstanding *before* any work happens.
3. **Gates before acting** — "wait for me to confirm" stops it from charging
   ahead. That's the observe → plan → *wait* opening of the loop.

Never let Claude start cold and never let it start *acting*. Reload, confirm,
then go. Same habit, every project.
